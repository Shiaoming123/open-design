# Poster Projects

Use this entry as a source-linked case library for excellent posters, event
key visuals, typographic one-sheets, and cultural print systems. Preserve the
smallest durable signal: composition, asset strategy, format behavior, and
reusable principles. Keep external work as inspiration-only unless the source
explicitly grants reuse rights; do not vendor artwork, fonts, videos, or
brand marks.

Each entry records:

- `project`: title, maker, source URL, medium, and format.
- `compositions`: focal image logic, type hierarchy, framing, and grid moves.
- `assets`: photography, illustration, typography, print finishes, and support media.
- `implementation`: format, complexity, and evidence limits.
- `capture`: date, source links, attribution, reuse policy, and capture depth.
- `status`: `lead`, `accepted`, `backfill-needed`, or `archived`.

Use `accepted` only when the source gives enough evidence to preserve the
reusable poster grammar; use `lead` when the poster set still needs a deeper
read.
